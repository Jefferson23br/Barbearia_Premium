1. Desenvolvimento do Sistema Web 
A CONTRATADA se obriga a desenvolver um sistema exclusivo, composto por: 
1.1. Site Público / Área Comercial 
•	Página institucional apresentando a barbearia, serviços e planos disponíveis. 
•	Área para compra de pacotes e planos, com integração de pagamento. 
•	Sistema de cadastro e login para clientes. 
•	Layout responsivo, compatível com dispositivos móveis e navegadores atuais. 

1.2. Painel do Cliente 
•	Exibição de planos adquiridos, ativos ou expirados. 
•	Consulta de saldo de usos restantes. 
•	Histórico completo de utilizações e atendimentos. 
•	Acesso a informações de pagamentos, faturas e recibos. 
•	Possibilidade de atualização de dados pessoais. 
•	Sistema de agendamento de horários, quando aplicável. 
•	Recebimento de notificações sobre marcações, vencimentos, promoções e alertas. 

1.3. Painel Administrativo da Barbearia 

•	Cadastro e gerenciamento de clientes. 
•	Cadastro, edição e controle de pacotes, serviços e planos. 
•	Controle de saldo de uso dos clientes, com registros de entrada e utilização. 
•	Agenda administrativa para organização dos atendimentos. 
•	Controle financeiro básico, incluindo pagamentos e relatórios. 
•	Envio de notificações individuais ou em massa, via e-mail ou WhatsApp, conforme recursos contratados. 
•	Dashboard com indicadores do sistema. 

1.4. Integrações 
•	Integração com gateway de pagamento (PIX, boleto, cartão, assinatura recorrente, conforme disponibilidade). 
•	Integração com serviços de notificação, quando aplicável. 

2. Entregáveis Inclusos 
A CONTRATADA entregará: 
•	Sistema completo hospedado em ambiente web ou servidor indicado pelo CONTRATANTE. 
•	Código-fonte, banco de dados configurado e estrutura operacional. 
•	Manual básico de uso e treinamento para a equipe da barbearia. 
•	Suporte técnico pelo período determinado no contrato. 

3. Personalização e Tecnologias 
O sistema será desenvolvido utilizando tecnologias modernas e atualizadas, garantindo alto desempenho, segurança e escalabilidade, incluindo: 
•	Front-end: React / Next.js 
•	Back-end: Node.js / NestJS 
•	Banco de Dados: MongoDB ou PostgreSQL 
•	Infraestrutura: Servidor cloud ou estrutura definida pelo CONTRATANTE 

4. Finalidade do Sistema 
O objetivo principal deste sistema é automatizar e digitalizar os processos internos da barbearia, proporcionando: 
•	Maior controle sobre os planos e clientes 
•	Redução de erros manuais 
•	Melhor experiência do cliente final 
•	Aumento da eficiência operacional 
•	Acesso rápido e organizado às informações 

5. Integração com Sistema Web para Emissão de Nota Fiscal 
•	Comunicação via API REST ou tecnologia equivalente disponibilizada pelo emissor de notas. 
•	Envio automático de informações como dados do cliente, produtos/serviços, impostos e valores. Registro e acompanhamento do status da NFe, NFCe ou NFSe (conforme o caso), incluindo retorno de protocolos, autorizações e eventuais rejeições. 
•	Geração automática de arquivos XML e DANFE.
