O que seria "API Externa"?
É uma integração com serviços de terceiros que seu sistema pode usar, como:
1. Sistemas de Pagamento
PagSeguro, Mercado Pago, Stripe
Para processar pagamentos online
2. Serviços de Notificação
SMS (Twilio, Zenvia)
WhatsApp Business API
Email (SendGrid, Mailgun)
Para enviar notificações automáticas
3. Sistemas de Nota Fiscal
NFe.io, Focus NFe, Bling
Para emitir notas fiscais automaticamente
4. Sistemas de Agendamento
Google Calendar, Calendly
Para sincronizar agendamentos
5. Sistemas de Gestão
ERPs, CRMs externos
Para sincronizar dados
Como funciona no sistema
Quando habilitada, você pode configurar:
URL Base da API: Endereço do serviço externo
Token da API: Chave de autenticação
Status: Habilitado/Desabilitado
