1. EXECUTAR BUILD:

   Linux/Mac:
   ./preparar-deploy.sh
   
   OU manualmente:
   npm install
   npm run build

2. LOCALIZAR ARQUIVOS:
   Pasta criada: "out/"
   Contém: index.html + todos os arquivos necessários

3. COPIAR PARA HOSTINGER:
   - Acesse Gerenciador de Arquivos
   - Vá até "public_html"
   - Copie CONTEÚDO da pasta "out" para "public_html"
   - Copie também o arquivo ".htaccess" para "public_html"

4. ACESSAR:
   http://seu-dominio-provisorio.com
   
   ✅ Tela de login aparece automaticamente!
